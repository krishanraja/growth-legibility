# Failure register

Every problem this repository has had to fix or guard against, with the code that guards it and the test that proves the guard. `npm run check:docs` (CI only) fails if a test named here no longer exists, so a rename or a deletion cannot silently drop a guard. Test references are written `` `file :: exact test name` ``. A row with no test yet says `new` and names the phase that adds it.

Conveyor learnings in `pipeline/stage-conveyor.json` are listed by id in the last column; `check:docs` requires each learning id to appear here with at least one named test.
